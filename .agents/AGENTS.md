# Workspace Rules & Instructions

## Rule: Backups Location
- All project backups MUST be stored in the central backup folder located at: `/Users/alexisamzdacruz/Desktop/dev/backup/`
- Format for backup directories: `/Users/alexisamzdacruz/Desktop/dev/backup/<ProjectName>_<YYYY-MM-DD_HH-MM-SS>` or `/Users/alexisamzdacruz/Desktop/dev/backup/<ProjectName>/<YYYY-MM-DD_HH-MM-SS>`
- NEVER create local `./backups/` or `./backup/` directories inside individual project working directories.

## Rule: No Em-Dashes (—)
- NEVER use em-dashes `—` in UI text, titles, meta tags, or descriptions across projects (EXCEPT for `dczimports`).
- Replace with clean punctuation like `:`, `.`, `,`, `|`, or `·` depending on context, or rephrase the sentence smoothly.

## Rule: Git Commit Messages in French
- ALL git commit messages MUST ALWAYS be written in French (`fr`).
- Format example: `feat: Ajout de l'ouverture automatique de l'inventaire Twitch Drops` ou `fix: Correction de la mise en cache CDN`
