Autoriser l'accès à Instagram

StreamPulse React a besoin de votre autorisation pour lire les commentaires des Reels Instagram directement depuis votre navigateur.

Ce que cela permet

  • Afficher les commentaires d'un Reel dans votre panneau live.
  • Aucune clé d'API ni abonnement : votre session existante est utilisée.
  • Les commentaires restent dans votre navigateur, rien n'est enregistré.

Vous pouvez retirer cet accès à tout moment depuis les paramètres de l'extension.
